## 🛠 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/sotariy/imstocker-test.git
cd imstoker-test
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить локальный сервер

```bash
npx json-server db.json --port 3000
```

### 4. Запустить проект

```bash
npm run dev
```
